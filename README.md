# vakil-pure-project

A web development project built in 2024 using JavaScript, EJS, and a custom build process.

This repository is preserved as part of my development portfolio and represents my work and technical experience at the time.

### Tech Stack

- JavaScript
- EJS (Embedded JavaScript Templates)
- HTML & CSS
- Custom Node.js build script

### Technical Decisions

Why EJS Instead of React?

The client requested a website built with vanilla web technologies, with the intention of converting it into a traditional WordPress theme later.

Rather than choosing React for a more familiar component-based development experience, I decided to use EJS (Embedded JavaScript Templates) alongside HTML, CSS, and JavaScript.

This approach offered several advantages:

- WordPress Compatibility: Generating traditional HTML markup made it easier to adapt the website into PHP-based WordPress templates.
- Reusable Templates: EJS partials allowed me to create reusable UI structures, reducing duplication and improving maintainability.
- Minimal Dependencies: The website didn't require a client-side framework or its associated runtime.
- Simpler Handoff: The resulting HTML, CSS, and JavaScript could be adapted by WordPress developers without rewriting React components.

The goal was to balance developer productivity, code reusability, and the client's long-term requirements, rather than introducing a framework that wasn't necessary for the project.
